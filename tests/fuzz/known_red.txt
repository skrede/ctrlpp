# Fuzz targets whose oracle is known unsound, with the repair each one owes.
#
# One target per line: the target binary's name, whitespace, then the reason.
# Blank lines and lines opening with '#' are ignored, and the list may be empty.
#
# Three consumers read this one file: the fuzz workflow, scripts/fuzz_smoke.sh
# and scripts/fuzz_seed_sweep.sh.
#
# A listed target is still explored and its outcome is still reported. An abort
# is reported as known red and does not fail the run. A listed target that stops
# aborting is reported as a stale waiver, which is not a failure either. These
# defects are reached by search, so a quiet run is evidence about the execution
# count before it is evidence about the defect: a line is deleted only after a
# re-triage at a larger execution count.
#
# A reason is corrected in place when the defect it names is repaired and the
# target still aborts. A stale reason invites the next reader to delete a line
# the evidence still supports.
