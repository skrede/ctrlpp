# l1

L1 adaptive controller with state predictor, projection-based adaptation, and
low-pass filtered control output. The controller decouples adaptation speed from
robustness &mdash; large adaptation gains are safe because the low-pass filter bounds
the control bandwidth. Supports SISO (NX=NU=1) and MIMO configurations with
matrix adaptation gains. The filter stage reuses ctrlpp's biquad infrastructure
through vector_biquad.

## Header and Alias

| Form | Header |
|------|--------|
| `ctrlpp::l1_controller<Scalar, NX, NU, Filter>` | `#include <ctrlpp/control/l1.h>` |

## Template Parameters

| Parameter | Constraint | Description |
|-----------|------------|-------------|
| `Scalar` | arithmetic type | Numeric type (e.g. `double`, `float`) |
| `NX` | `std::size_t`, default `1` | State dimension |
| `NU` | `std::size_t`, default `1` | Input dimension |
| `Filter` | `vector_discrete_filter<Filter, Vector<Scalar, NU>>`, default `vector_biquad<Scalar, NU>` | Low-pass filter type for control output |

`NX` must equal `NU` (a square predictor), enforced by a `static_assert`. The
reference feedforward gain is formed by inverting the predictor DC gain, which
requires a square, invertible model. The general non-square feedforward gain
`k_g = -(C (I - A_m)^{-1} B)^{-1}` is not yet implemented.

## Type Aliases

```cpp
using config_type = l1_config<Scalar, NX, NU>;
using state_type  = Vector<Scalar, NX>;
using input_type  = Vector<Scalar, NU>;
```

## Config: l1_config

```cpp
template <typename Scalar, std::size_t NX, std::size_t NU>
struct l1_config;
```

Header: `#include <ctrlpp/control/l1_config.h>`

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `predictor_model` | `discrete_state_space<Scalar, NX, NU, NX>` | zero | Desired closed-loop dynamics (A_m, B_m, C_m, D_m) |
| `gamma` | `Matrix<Scalar, NU, NU>` | Identity | Adaptation gain matrix (SPD; large values are safe) |
| `theta_min` | `Vector<Scalar, NU>` | `-infinity` | Elementwise lower bound for projection |
| `theta_max` | `Vector<Scalar, NU>` | `+infinity` | Elementwise upper bound for projection |
| `x_hat_0` | `Vector<Scalar, NX>` | zero | Initial predictor state |
| `sigma_hat_0` | `Vector<Scalar, NU>` | zero | Initial uncertainty estimate |

The `predictor_model` uses the desired closed-loop dynamics (A_m), not the unknown
plant dynamics. `gamma` is the adaptation gain &mdash; L1 allows large values (1000+)
because robustness comes from the filter bandwidth, not gain tuning. `theta_min`
and `theta_max` define elementwise projection bounds that keep the uncertainty
estimate bounded. They default to an unbounded range (`-infinity` to `+infinity`),
so a default-constructed config adapts freely; set finite bounds to enable the
elementwise projection.

## Filter Construction

Two construction paths for configuring the low-pass filter that decouples
adaptation from control:

### Convenience Constructor

```cpp
l1_controller(const config_type& cfg, Scalar cutoff_hz, Scalar sample_hz);
```

Builds a 2nd-order Butterworth low-pass via `vector_biquad::low_pass()`, replicated
across NU channels. `cutoff_hz` must be strictly less than `sample_hz / 2` (Nyquist
limit).

### Direct Constructor

```cpp
l1_controller(const config_type& cfg, Filter filter);
```

Accepts any type satisfying `vector_discrete_filter`. Use for higher-order filters
or custom filter types.

### Constructor Validation

Both constructors validate the predictor model and throw `std::invalid_argument` if:

- `(I - A_m)` is singular (predictor has a unit eigenvalue)
- The DC gain `(I - A_m)^{-1} * B` is singular (near-zero steady-state gain)
- The feedforward gain `K_r` is non-finite (ill-conditioned predictor model)

```cpp
// 4th-order Butterworth at 5 Hz, 100 Hz sample rate
auto filter = ctrlpp::make_vector_butterworth<4, 1>(5.0, 100.0);
ctrlpp::l1_controller<double, 1, 1, decltype(filter)> ctrl(cfg, std::move(filter));
```

```cpp
// 4th-order Chebyshev Type I with 1 dB passband ripple
auto filter = ctrlpp::make_vector_chebyshev1<4, 1>(5.0, 100.0, 1.0);
ctrlpp::l1_controller<double, 1, 1, decltype(filter)> ctrl(cfg, std::move(filter));
```

## Class Methods

### evaluate

```cpp
auto evaluate(const state_type& x, const input_type& r) -> input_type;
```

Computes the filtered control output for the current time step. Internally
executes the full L1 pipeline: state predictor update, prediction error
computation, projection-based adaptation, feedforward plus cancellation, and
low-pass filtering. Call once per time step.

### x_hat

```cpp
auto x_hat() const -> const state_type&;
```

Returns a const reference to the current predicted state vector.

### sigma_hat

```cpp
auto sigma_hat() const -> const input_type&;
```

Returns a const reference to the current matched uncertainty estimate vector.

### tracking_error

```cpp
auto tracking_error() const -> const state_type&;
```

Returns a const reference to the prediction error (x_hat - x).

### theta

```cpp
auto theta() const -> const input_type&;
```

Returns a const reference to the adapted parameter vector. Alias for `sigma_hat()`,
named for consistency with MRAC's `theta_x` / `theta_r`.

### reset

```cpp
void reset();
```

Resets predictor state, uncertainty estimate, control history, and filter state to
their initial values from the config.

## Usage Examples

### SISO: First-Order Plant Tracking

```cpp
// Usage: gnuplot -p -e "set datafile separator ','; set key autotitle columnheader;
//   plot '<./ctrlpp_l1_01_tracking' using 1:2 with lines title 'reference',
//        '' using 1:3 with lines title 'plant',
//        '' using 1:4 with lines title 'predictor'"

#include "ctrlpp/control/l1.h"

#include <iomanip>
#include <iostream>

int main()
{
    using controller = ctrlpp::l1_controller<double>;
    using config = controller::config_type;

    ctrlpp::discrete_state_space<double, 1, 1, 1> pred_model{};
    pred_model.A(0, 0) = 0.9;
    pred_model.B(0, 0) = 0.1;
    pred_model.C(0, 0) = 1.0;

    config cfg{};
    cfg.predictor_model = pred_model;
    cfg.gamma(0, 0) = 1000.0;
    cfg.theta_min[0] = -10.0;
    cfg.theta_max[0] = 10.0;

    controller ctrl(cfg, 5.0, 100.0);

    constexpr double a_p = 0.8, b_p = 0.5;
    double x_plant = 0.0;

    ctrlpp::Vector<double, 1> r;
    r[0] = 1.0;

    for (int k = 0; k < 500; ++k) {
        ctrlpp::Vector<double, 1> x;
        x[0] = x_plant;
        auto u = ctrl.evaluate(x, r);

        std::cout << std::fixed << std::setprecision(6)
                  << k << "," << 1.0 << "," << x_plant << ","
                  << ctrl.x_hat()[0] << "," << u[0] << ","
                  << ctrl.sigma_hat()[0] << "\n";

        x_plant = a_p * x_plant + b_p * u[0];
    }
}
```

### MIMO: Two-Channel Tracking

```cpp
#include "ctrlpp/control/l1.h"

#include <iomanip>
#include <iostream>

int main()
{
    constexpr std::size_t NX = 2;
    constexpr std::size_t NU = 2;

    using controller = ctrlpp::l1_controller<double, NX, NU>;
    using config = controller::config_type;

    ctrlpp::discrete_state_space<double, NX, NU, NX> pred_model{};
    pred_model.A << 0.9, 0.0,
                    0.0, 0.85;
    pred_model.B << 0.1, 0.0,
                    0.0, 0.15;
    pred_model.C = ctrlpp::Matrix<double, NX, NX>::Identity();

    config cfg{};
    cfg.predictor_model = pred_model;
    cfg.gamma = 1000.0 * ctrlpp::Matrix<double, NU, NU>::Identity();
    cfg.theta_min = -10.0 * ctrlpp::Vector<double, NU>::Ones();
    cfg.theta_max = 10.0 * ctrlpp::Vector<double, NU>::Ones();

    controller ctrl(cfg, 5.0, 100.0);

    ctrlpp::Matrix<double, NX, NX> A_p;
    A_p << 0.8, 0.1,
           0.0, 0.7;
    ctrlpp::Matrix<double, NX, NU> B_p;
    B_p << 0.5, 0.0,
           0.0, 0.4;

    ctrlpp::Vector<double, NX> x_plant = ctrlpp::Vector<double, NX>::Zero();
    ctrlpp::Vector<double, NU> r;
    r << 1.0, 0.5;

    for (int k = 0; k < 500; ++k) {
        auto u = ctrl.evaluate(x_plant, r);

        std::cout << std::fixed << std::setprecision(6)
                  << k << ","
                  << r[0] << "," << x_plant[0] << "," << ctrl.x_hat()[0] << ","
                  << r[1] << "," << x_plant[1] << "," << ctrl.x_hat()[1] << ","
                  << u[0] << "," << u[1] << "\n";

        x_plant = A_p * x_plant + B_p * u;
    }
}
```

## Algorithm

The L1 `evaluate()` pipeline executes these steps each time step:

1. **State predictor:** x_hat = A_m * x_hat_prev + B * (u_prev + sigma_hat)
2. **Prediction error:** x_tilde = x_hat - x
3. **Adaptation:** sigma_hat -= Gamma * B^T * x_tilde, clamped to [theta_min, theta_max]
4. **Control:** u_raw = K_r * r - sigma_hat
5. **Filter:** u = C(z) * u_raw
6. **Return** u

K_r (feedforward gain) is computed internally from the predictor model DC gain when
NX == NU: K_r = ((I - A_m)^{-1} * B)^{-1}. The constructor validates that this
inversion is well-conditioned and throws if not (see Constructor Validation above).

Reference: Hovakimyan & Cao, "L1 Adaptive Control Theory", 2010, Ch. 2.

## Design Notes

- The low-pass filter IS the robustification mechanism &mdash; L1 does not need dead-zone
  or sigma-modification policies
- Large adaptation gains (gamma >> 1) are typical and safe; the filter bandwidth
  determines closed-loop bandwidth
- For NX != NU, the user should scale the reference appropriately
